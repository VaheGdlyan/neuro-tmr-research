# Neuro_TMR Product Definition

## Overview

Neuro_TMR is a software platform that enables **real-time closed-loop Targeted Memory Reactivation (TMR)** using EEG-based wearable devices.

Rather than developing new EEG hardware, Neuro_TMR functions as an intelligent software layer that integrates with existing EEG wearable systems. The platform continuously analyzes incoming EEG signals, detects memory-relevant sleep stages in real time, and delivers precisely timed auditory cues to facilitate memory consolidation during sleep.

The product is built upon decades of neuroscience and sleep research demonstrating that memory reactivation during specific stages of sleep—particularly Slow-Wave Sleep (SWS)—can produce measurable improvements in memory consolidation when cues are delivered at the appropriate time.

---

# Product Vision

The long-term vision of Neuro_TMR is to transform sleep from a passive biological process into an active period for scientifically guided memory consolidation.

Instead of focusing on sleep tracking alone, Neuro_TMR aims to provide a new category of neurotechnology that enables users to enhance learning through real-time interaction with their sleeping brain.

The platform is designed to become the intelligence layer that converts physiological sleep data into personalized memory enhancement.

---

# Product Philosophy

The development of Neuro_TMR follows a research-first methodology.

Every engineering decision is derived from scientific evidence rather than assumptions.

The product is intentionally designed to maximize scientific validity before optimizing comfort or scalability.

The first objective is not to build the most comfortable wearable.

The first objective is to build the most scientifically reliable closed-loop TMR system capable of producing measurable improvements in memory consolidation.

---

# Product Architecture

The Neuro_TMR platform consists of two major components.

## Existing EEG Hardware

The EEG wearable is responsible for:

- Continuous acquisition of brain activity
- Real-time EEG signal generation
- Communication with the Neuro_TMR software

Neuro_TMR does not replace or compete with EEG hardware manufacturers.

Instead, it utilizes their real-time EEG data as the input for the memory enhancement system.

---

## Neuro_TMR Intelligence Layer

The Neuro_TMR software continuously performs:

- EEG signal acquisition
- Signal preprocessing
- Real-time sleep-stage estimation
- Slow-Wave Sleep (SWS) detection
- Confidence estimation
- Closed-loop cue scheduling
- Auditory cue timing
- Session logging
- User progress monitoring

The intelligence layer determines **when** memory cues should be delivered based on ongoing brain activity.

This software layer represents the core innovation of the product.

---

# System Workflow

The complete Neuro_TMR workflow is:

1. User learns new information during wakefulness.
2. Learning material is associated with predefined auditory cues.
3. During sleep, an EEG wearable continuously records brain activity.
4. Neuro_TMR receives the EEG stream in real time.
5. The software estimates the current sleep stage.
6. When Slow-Wave Sleep is detected with sufficient confidence, the system triggers an auditory cue.
7. The cue reactivates the associated memory.
8. Memory consolidation occurs during sleep.
9. The user receives objective and subjective learning feedback after waking.

# Business Model

Neuro_TMR is designed as a **software-first B2B platform**.

Rather than manufacturing EEG hardware, the platform integrates with existing EEG wearable manufacturers.

### EEG Hardware Partner

Provides:

- EEG sensors
- Signal acquisition
- Wearable device
- Hardware ecosystem

### Neuro_TMR

Provides:

- Closed-loop TMR algorithms
- Real-time sleep-stage intelligence
- Cue scheduling
- Memory enhancement functionality
- User analytics
- Software updates

The EEG manufacturer receives a new premium software capability without developing TMR technology internally.

Neuro_TMR receives access to real-time EEG data and distribution through existing hardware ecosystems.

# Product Validation Strategy

The development strategy follows a staged validation process.

## Phase 1

Scientific validation

Objective:

Demonstrate that an EEG-based closed-loop TMR system can reliably improve memory under controlled conditions.

---

## Phase 2

Real-world validation

Objective:

Evaluate usability, reliability, and measurable learning improvements in home environments.

---

## Phase 3

Commercial validation

Objective:

Determine whether users perceive sufficient value to support long-term adoption and commercial deployment.

---

## Phase 4

Platform expansion

After the EEG-based platform has been scientifically validated, investigate alternative sensing technologies such as PPG-based wearables to improve comfort, accessibility, and scalability.
