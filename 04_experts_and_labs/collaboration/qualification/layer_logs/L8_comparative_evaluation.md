# L8 — Comparative Evaluation & Ranking

## Purpose

L8 compares the **120 opportunities that completed L7** and determines their relative strategic value to Neuro-TMR.

Unlike previous qualification layers, L8 is explicitly comparative and may substantially reduce the active opportunity universe.

The governing principle is:

> **Rank opportunities according to their expected contribution to Neuro-TMR's current and foreseeable bottlenecks — not prestige, visibility, or theoretical relevance alone.**

The evaluation horizon is:

> **Current Phase II and the nearest credible pathway toward EEG-based Neuro-TMR V1 technical, scientific, and human validation.**

Longer-term value is preserved separately under **Future Strategic Value**.

---

# 1. Two Independent Rankings

Every one of the 120 L7 candidates receives **two separate evaluations**.

## A. Within-Family Score — 0–100

Measures:

> **How strong is this opportunity relative to other opportunities providing the same functional type of value?**

Each F1–F8 family has its own fixed criteria.

The result produces a **within-family ranking**.

---

## B. Global Cross-Family Score — 0–100

Measures:

> **How much strategic value can this opportunity realistically create for Neuro-TMR as a whole?**

The global score uses the same criteria for all 120 candidates.

The family score and global score are **never added together**.

They answer different questions.

---

# 2. Evidence-Based Rating Scale

Every criterion uses an integer rating from `0–5`.

| Rating | Meaning                                               |
| -----: | ----------------------------------------------------- |
|    `0` | No meaningful value or evidence contradicts relevance |
|    `1` | Very weak                                             |
|    `2` | Limited                                               |
|    `3` | Credible / moderate                                   |
|    `4` | Strong                                                |
|    `5` | Exceptional, direct, and well-supported               |

Weighted points are calculated as:

> **Criterion Points = Weight × Rating / 5**

No intermediate ratings such as `3.5` or `4.2` are permitted.

This avoids false precision and keeps scoring reproducible.

# 4. Global Cross-Family Score

All 120 opportunities use the following universal framework.

| Criterion                            |  Weight |
| ------------------------------------ | ------: |
| Contribution to Neuro-TMR objectives |      25 |
| Critical bottleneck resolution       |      20 |
| Realistic actionability / access     |      15 |
| Expected impact if successful        |      10 |
| Non-substitutability / unique value  |      10 |
| Cross-project leverage               |      10 |
| Time-to-value                        |       5 |
| Evidence confidence                  |       5 |
| **Total**                            | **100** |

## Criterion Definitions

### Contribution to Neuro-TMR Objectives

How directly the opportunity advances the defined scientific, technical, validation, institutional, or translational goals of Neuro-TMR.

### Critical Bottleneck Resolution

Whether the opportunity addresses something currently constraining progress that Neuro-TMR cannot easily solve alone.

### Realistic Actionability / Access

Whether a credible path exists to actually obtain value from the opportunity.

### Expected Impact

Magnitude of benefit to Neuro-TMR if the opportunity succeeds.

### Non-Substitutability / Unique Value

How difficult it would be to replace the opportunity with another realistic candidate providing equivalent capability.

### Cross-Project Leverage

Whether the opportunity can unlock multiple project dimensions rather than only one narrow benefit.

### Time-to-Value

How soon useful value could realistically reach the project.

### Evidence Confidence

How strong and current the evidence is supporting the scoring judgment.

# 5. Dependency Penalty

After raw scoring, one discrete dependency penalty may be applied:

`0, -2, -4, -6, -8, -10, or -12`

| Penalty | Operational Meaning                                                                                                |
| ------: | ------------------------------------------------------------------------------------------------------------------ |
|     `0` | No material external blocker                                                                                       |
|    `-2` | Minor preparation, primarily under Neuro-TMR's control                                                             |
|    `-4` | One meaningful but realistically tractable external dependency                                                     |
|    `-6` | Material institutional, host, commercial, approval, or cycle dependency                                            |
|    `-8` | Major external gate or several interacting dependencies                                                            |
|   `-10` | Very difficult activation path or substantial delay before useful value                                            |
|   `-12` | Strategically credible but not realistically activatable within the current or nearest Neuro-TMR execution horizon |

The same opportunity-level dependency penalty is used when interpreting both family and global scores.

## Double-Counting Rule

A dependency penalty must **not** repeat ordinary difficulty already captured by criteria such as:

* accessibility;
* eligibility;
* timing;
* practical feasibility;
* integration openness.

The penalty is used only for a **distinct external blocker** beyond ordinary difficulty.

Example:

> Having to submit an application is not automatically a penalty.

But:

> Requiring an institutional host that Neuro-TMR does not currently possess may justify a dependency penalty.

---

# 6. Hard Blockers

Candidates with:

* no credible access route;
* no meaningful remaining contribution;
* a materially obsolete opportunity;
* an effectively impossible structural requirement;
* or clearly dominated value with no strategic reason to preserve them

should not receive artificially large penalties.

They may instead receive:

* `DEFER`
* or `DROP`

after full comparative scoring.

---

# 7. Additional Interpretation Fields

Every opportunity also receives four qualitative fields.

## Substitutability

* **Low** — few or no realistic alternatives provide the same capability
* **Medium** — alternatives exist but meaningful capability is lost by substitution
* **High** — several realistic alternatives provide broadly comparable value

Substitutability does not create an additional numerical bonus or penalty.

---

## Current Priority

Assigned only **after complete ranking**:

* Low
* Medium
* High
* Critical

It summarizes present strategic importance and is not an independent scoring input.

---

## Future Strategic Value

* Low
* Medium
* High
* Critical

This captures value beyond the immediate Phase II / V1 horizon.

It protects long-term optionality without artificially inflating current priority.

---

## Evaluation Confidence

* **Low** — ranking materially depends on incomplete or indirect evidence
* **Medium** — evidence is sufficient, but meaningful uncertainty remains
* **High** — strong and current evidence supports the major scoring judgments

---

# 8. Family Assignment Rule

Every opportunity enters L8 with one primary F1–F8 family defined in the frozen L7 qualified universe.

Family assignment determines which within-family rubric is applied.

Once official scoring begins, family assignments must not be changed simply because another family would produce a more favorable score.

A genuine factual classification error may be corrected only if:

1. the reason is documented;
2. the correction occurs before final ranking;
3. the change is recorded in the L8 ledger.

Secondary value across other families is captured through **Cross-Project Leverage**, not through multiple family scores.

---

# 9. Previous Layer Independence

Previous statuses such as:

* `L4_DIRECT_HIGH`
* `L5_HIGH_DISTINCT`
* `L6_ACTIONABLE`
* `L6_RESERVE_CANDIDATE`

are evidence and context.

They are **not converted mechanically into L8 points**.

For example:

> `L6_ACTIONABLE` does not automatically receive a scoring bonus.

L8 must evaluate the underlying evidence using the frozen L8 rubric.

A previous `L6_RESERVE_CANDIDATE` may outrank a previous `L6_ACTIONABLE` candidate if comparative evidence supports that result.

---

# 10. Ranking Procedure

L8 is executed in the following order.

### Step 1 — Freeze Method

Freeze:

* candidate population;
* family assignment;
* F1–F8 criteria;
* global criteria;
* rating definitions;
* dependency penalties;
* interpretation rules.

### Step 2 — Score All 120 Candidates

Every candidate receives:

* family raw score;
* global raw score;
* dependency penalty;
* adjusted family score;
* adjusted global score.

No candidate is eliminated during scoring.

### Step 3 — Produce Within-Family Rankings

Rank candidates independently inside F1–F8.

### Step 4 — Produce Global Ranking

Rank all 120 candidates according to adjusted global strategic value.

### Step 5 — Evaluate Portfolio Structure

Review:

* substitutability;
* redundancy;
* strategically unique capabilities;
* current versus future value;
* family coverage.

### Step 6 — Assign Final L8 Decisions

Only after all 120 candidates have been scored and ranked may they receive:

* `KEEP`
* `RESERVE`
* `DEFER`
* `DROP`

---

# 11. L8 Decision Semantics

## `KEEP`

Strong comparative value and justified continuation into the active Path E portfolio.

## `RESERVE`

Genuinely useful opportunity, but comparatively weaker, more substitutable, or lower priority than stronger current alternatives.

## `DEFER`

Strategically valuable, but meaningful use depends on a later stage, trigger, eligibility condition, institutional structure, technological maturity, or future cycle.

## `DROP`

Comparative evidence shows insufficient marginal value relative to stronger available alternatives.

A candidate should not be dropped solely because of family size or an arbitrary survival quota.

---

# 12. Tie Rule

When adjusted scores are equal, comparison proceeds in this order:

1. higher raw score;
2. higher score on the highest-weight criterion;
3. higher evaluation confidence.

If candidates remain genuinely indistinguishable, they receive the **same rank**.

Artificial precision must not be created where the evidence does not support separation.

---

# 13. Reduction Principle

L8 is expected to reduce the active opportunity universe.

However:

> **No fixed survival number or percentage is imposed before scoring.**

Reduction is evidence-driven.

A strategically unique candidate may be preserved despite a lower numerical rank when no realistic substitute provides the same capability.

Likewise, a famous or high-quality opportunity may still be removed if stronger and more actionable alternatives provide equivalent value.

---

# 14. Methodological Integrity

The criteria and weights defined in this document are **frozen before official scoring begins**.

They must not be modified simply because:

* a preferred opportunity scores unexpectedly low;
* a famous institution ranks below a less prestigious candidate;
* a family receives lower scores than expected;
* the final reduction is larger or smaller than anticipated.

If a genuine methodological defect is discovered during execution, scoring must stop and the change must be explicitly documented before restarting the affected evaluation.
