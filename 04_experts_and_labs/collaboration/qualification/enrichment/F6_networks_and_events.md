# F6 — Networks / Events / Multipliers

## Purpose

Evaluate scientific societies, conferences, EEG communities, Armenian/diaspora networks, innovation ecosystems, and networking opportunities.

## Main Questions

L7 examined:

- whether the network/event is active;
- participation timing;
- scientific fit;
- collaboration-discovery potential;
- presentation opportunities;
- mentorship and introductions;
- usefulness at the current project stage.

## Main Contribution Types

These opportunities can provide:

- scientific connections;
- introductions to laboratories;
- visibility;
- presentation opportunities;
- mentorship;
- collaboration discovery;
- ecosystem access.

## L7 Finding

These opportunities generally do not directly solve a core scientific or technical bottleneck.

Instead, they function as **multipliers**.

Their value becomes larger when Neuro-TMR has:

- a concrete prototype;
- results to present;
- a collaboration request;
- a specific technical problem;
- or a clear funding objective.

Timing is therefore important because many operate through annual events or application cycles.
