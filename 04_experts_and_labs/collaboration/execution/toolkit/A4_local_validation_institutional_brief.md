---

## 1. Purpose

A4 defines how Neuro-TMR should approach **local Armenian institutions** for realistic scientific, technical, and later clinical validation support.

It is not a request to immediately run a human TMR experiment.

> **A4 converts “local collaboration” into specific institutional roles, concrete asks, and staged validation pathways.**

The objective is to build an Armenian support structure around Path V without overclaiming project maturity or requesting infrastructure before a defined need exists.

---

## 2. Core Principle

Local institutions should not be approached with:

> “I have a neuroscience project and want to collaborate.”

They should be approached with:

> **“Neuro-TMR has reached a defined technical/scientific stage. This is the specific capability we need, this is what we already have, and this is the smallest useful next step.”**

The first institutional goal is usually a **feasibility conversation**, not a formal experiment.

## 4. Staged Local Validation Path

A4 defines a simple progression.

```text
Stage 0
Path V works on public/open data
        ↓
Stage 1
Technical consultation / EEG feasibility
        ↓
Stage 2
Institutional hosting or equipment-access discussion
        ↓
Stage 3
Reference EEG / PSG comparison planning
        ↓
Stage 4
Formal human validation only if scientifically justified,
institutionally supported, and ethically approved
```

### Important boundary

> **Neuro-TMR should not jump from software development directly to a human TMR study.**

A local institution becomes valuable first by helping validate assumptions, equipment, methodology, signal quality, and feasibility.

---

## 5. What Neuro-TMR Can Present

For a local institutional meeting, Neuro-TMR can present a concise evidence package:

- completed Phase I scientific research;
- full scientific manuscript;
- current EEG-based stage-aware V1 rationale;
- A1 — data and benchmark principles;
- A2 — EEG hardware requirements;
- A3 — scientific collaboration framing;
- Path V plan or early technical result when available.

The project should be described as:

> **an evidence-based neuroscience-to-neurotechnology research project entering technical validation**

—not as a clinically validated product.

## 7. Standard Institutional Ask Structure

Every A4-based outreach should contain five elements:

```text
1. What Neuro-TMR is
2. What stage the project has reached
3. Why this institution specifically matters
4. One concrete capability/question we need
5. One small requested next step
```

Preferred first next step:

> **20–30 minute feasibility conversation**

—not equipment access, patient recruitment, or a full study commitment.

---

## 8. What We Should Not Ask For Yet

Until Path V produces a defined validation requirement, Neuro-TMR should not request:

- patient recruitment;
- overnight human TMR experiments;
- clinical endorsement;
- ethics approval for an undefined protocol;
- unrestricted access to clinical EEG/PSG data;
- expensive equipment commitments;
- formal institutional sponsorship without a clear purpose.

A4 exists partly to prevent premature escalation.

---

## 9. Local Validation Decision Rule

A local validation request becomes justified when all four conditions are true:

**1. Defined Question**  
There is a specific technical/scientific uncertainty.

**2. Internal Preparation**  
Path V has done what can reasonably be done using open data/software first.

**3. Institutional Fit**  
The institution has a capability that directly resolves the remaining uncertainty.

**4. Proportionate Ask**  
The requested support is no larger than necessary.

If one of these is missing, the request should be delayed or narrowed.

---

## 10. Governance Boundary

Any future work involving human participants, clinical recordings, new data collection, or stimulation must move through the appropriate institutional and ethics pathway.

A4 does not define that pathway in detail.

It establishes the rule:

> **No human validation proceeds informally. Institutional authorization, consent requirements, data governance, and ethics review must be clarified before recruitment or experimentation.**
