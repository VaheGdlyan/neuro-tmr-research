## 2. Original Scientific Question

The outreach asked whether a scientifically defensible closed-loop TMR system must directly verify that the intended memory representation was reactivated, or whether system-level and behavioral validation can be sufficient.

**Core question:** Does V1 need memory-level neural confirmation of reactivation, or can it remain scientifically defensible without such decoding if cue delivery is controlled and a robust behavioral effect is demonstrated?

---

## 3. Response

### 2026-08-18 — Scientific Response

Professor Schechtman wrote:

> “I think that a device or algorithm that produces a robust behavioral effect would be scientifically defensible, even without direct evidence for reactivation. You would likely need to provide evidence that cues didn't substantially change sleep architecture (ie, didn't cause too many arousals and compromise sleep) and that they were presented during sleep and not wakefulness.”

He closed with encouragement for the work.

## 4. Scientific Interpretation

This provides a concrete validation boundary for a first-generation system.

The response indicates that **direct neural confirmation of the intended memory reactivation is not necessarily required for scientific defensibility** if the system can show a robust behavioral effect.

However, the system should provide evidence that:

- cues were delivered during sleep rather than wakefulness;
- cueing did not cause excessive arousals;
- sleep architecture was not substantially compromised;
- the intervention produced a robust behavioral effect.

This simplifies the V1 validation problem by separating **mechanistic proof of memory reactivation** from **evidence that the intervention works without materially damaging sleep**.

The response does **not** determine:
- N3 versus N2;
- stage-aware versus phase-aware control;
- EEG versus peripheral sensing.
